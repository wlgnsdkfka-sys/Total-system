# TC / JPT GUI v12

[**수정된 GUI v12 ZIP 다운로드**](https://github.com/wlgnsdkfka-sys/Total-system/raw/refs/heads/gui-download-20261021/downloads/TC_JPT_GUI_v12.zip)

**bulk TC9~12를 4번 전기로 교정에서 제외**했습니다. 전기로 초기 교정은 TC1~8만 사용하고, bulk는 3번 탭의 끓는 물 기준 100°C 오프셋만 적용합니다.

## 이번 수정

- **4번 탭**: TC1~8만 NI 설정·측정·3분 안정화 판정·보정식 계산에 사용합니다. bulk를 전기로에 넣거나 입력하지 않아도 됩니다. 원시 CSV/ZIP, 교정 데이터 JSON/CSV, 표와 그래프도 TC1~8입니다. bulk가 없거나 흔들려도 전기로 교정을 진행합니다.
- **3번 탭**: 실제 물이 충분히 끓을 때 TC1~12의 기준 원시온도를 측정합니다. TC1~8은 초기 교정 후 실험 오프셋을 더하고, bulk TC9~12는 `bulk 오프셋 = 100 − 비등 시 원시온도`만 저장합니다. TC1~8 기준온도를 바꿔도 bulk 기준은 100°C입니다.
- **bulk 실시간 표시**: `현재 bulk 온도 = 현재 원시온도 + 저장한 bulk 오프셋`입니다. 비등 원시값 98.7°C를 +1.3°C로 보정하면 이후 원시값 99.2°C는 **100.5°C**로 표시합니다. 이후 값을 계속 100°C로 고정하지 않습니다.
- **보정 분리**: 전기로 보정식을 새로 적용·변경·해제해도 bulk 오프셋은 유지합니다. 3번 비등 보정을 해제하면 bulk는 원시온도를 표시합니다. 1번 탭에는 bulk 오프셋 적용 여부도 표시합니다.

## 전체 순서

**5번 수식·상수 저장 → 4번 TC1~8 전기로 초기 교정 → 3번 실험 오프셋과 bulk 100°C 기준 보정 → 1번 최종 온도 측정·기록 → 2번 단계별 자동 보일링 커브**입니다.

기존 단계별 평균·표준편차, 30초 실시간 σ, 임계온도 실시간 변경·비프음, OFF index −1%, 파일 저장·불러오기, 단계별 자동 커브는 유지합니다. 5번 상수는 실행 중에도 저장 가능하며 현재 실험은 시작 당시 상수를 사용하고 다음 실험부터 변경값을 적용합니다. 2번에서 최신 저장 상수로 재계산할 수 있습니다. CSV·표 직접 편집 시 자동 커브 갱신을 꺼서 수동 데이터를 유지합니다.

3번의 안정 구간은 TC1~12, 4번은 TC1~8을 확인합니다. 기본 연속 180초에서 해당 채널 모두 σ ≤ 0.1°C, 최대−최소 ≤ 0.5°C이며 시작 전 조정할 수 있습니다. 한 번에 하나의 측정만 실행하고, 전기로 자체는 기존 장치에서 조작합니다.

## 저장 데이터와 이전 버전 이동

새 초기 교정 JSON은 스키마 버전 2로 TC1~8을 명시합니다. 새 CSV는 `reference_c,TC1_raw_c,...,TC8_raw_c`를 사용합니다. 저장·불러오기와 자동 저장을 지원합니다.

v10/v11의 12채널 초기 데이터·적용본도 읽습니다. 기존 데이터·계수 무결성을 확인한 뒤 TC1~8만 유지하고 bulk 초기 교정을 제외합니다. 저장된 비등 원시 기준이 있으면 bulk 오프셋을 `100 − bulk 기준 원시온도`로 다시 계산합니다. 원시 기준이 없으면 3번 탭에서 먼저 비등 보정을 저장하세요. 이전 안정 구간의 근거·해시는 당시 원본 기록으로 보관하며 과거 실험 파일은 바꾸지 않습니다.

기존 앱을 종료하고 새 ZIP을 다른 폴더에 모두 푼 뒤 **`TC_JPT_GUI/실행하기.bat`**를 실행하세요. Python 3.10 이상이 필요합니다. 기존 보정을 옮기려면 앱을 종료한 상태에서 이전 `results/temperature_calibration.json`, `initial_calibration_data.json`, `calculation_settings.json`, 필요하면 `leak_settings.json`을 새 폴더의 `results`로 복사합니다. 또는 초기 데이터 JSON/CSV를 4번 탭에서 불러와 계산·적용합니다. 원시 ZIP과 과거 실험 폴더도 별도 보관하세요.

자세한 절차는 ZIP의 **`docs/workflow.md`**, 교정 파일 형식은 **`docs/initial_calibration.md`**, NI 설치는 **`docs/ni_calibration.md`**를 참고하세요.

## 검증 범위

자동 검사 **195개**와 배포본 압축 해제 후 검사를 통과했습니다. NI 대역으로 전기로 AI 8개만 생성·읽기, bulk 누락·변동과 무관한 전기로 안정화, 8채널 데이터 저장·불러오기, bulk 100°C 오프셋 및 이후 실제 변화, 전기로 보정 변경 시 bulk 오프셋 유지, 이전 12채널 데이터·적용본 전환을 확인했습니다.

Chromium에서 4번 탭의 8채널 NI 설정·CSV 수집·교정·원시 ZIP, 3번 bulk 오프셋 미리보기·적용, 1번 bulk 100.50/101.25°C 실시간 표시, 자동 커브, 중간 상수 저장, 수동 데이터 보존, 재실행과 모바일을 확인했습니다. 실제 v11 파일의 업그레이드도 확인했습니다.

**실제 NI는 3·4번 보정용 온도 읽기 전용이며, 1번 실험은 가상/CSV 입력입니다. 실제 레이저·셔터 출력 제어는 미연결입니다.** 실제 NI 정확도와 Windows 실행은 이 클라우드에서 검증하지 않았습니다. 가상·CSV에는 별도 패키지가 없고 NI 입력은 NI-DAQmx와 `python -m pip install -r requirements-ni.txt`가 필요합니다.
