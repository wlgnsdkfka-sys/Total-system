# TC / JPT 보일링 실험 GUI v18

[TC_JPT_GUI_v18.zip 다운로드](https://github.com/wlgnsdkfka-sys/Total-system/raw/refs/heads/gui-download-20261021/downloads/TC_JPT_GUI_v18.zip)

ZIP을 모두 풀고 Python 3.10 이상이 설치된 Windows PC에서 `실행하기.bat`를 실행하세요. NI 실측 입력에는 NI-DAQmx 드라이버와 `requirements-ni.txt` 패키지가 필요합니다.

v18은 1번 탭의 **측정 중지 옆 ‘대기 상태로’ 버튼**을 추가했습니다. 실험 종료·중단 후 누르면 시간 표시와 온도 알림등이 대기로 돌아갑니다. 이전 기록·그래프·커브·결과 다운로드와 설정은 유지합니다. 새 실험은 별도 결과 폴더에 저장합니다. 실험·보정 측정 중에는 대기 전환을 사용할 수 없습니다. 이 버튼은 추가 장비 출력 명령을 보내거나 셔터 인터록을 해제하지 않습니다.

기존 7개 탭, 보정 전/전기로 보정/실측 오프셋의 세 CSV, NI 고속 실험 입력·고해상도 보정, myDAQ 셔터 연결 복구, 중복 실행 방지 기능을 유지합니다. 브라우저만 닫으면 서버가 남아 있으며 다시 실행하면 기존 프로그램을 재사용합니다. 완전히 종료하려면 화면의 ‘프로그램 종료’를 사용하세요.

실제 레이저 OFF·출력 설정·ON과 자동 시작 초기화는 아직 미연결입니다. NI 셔터 출력과 레이저 발진의 실제 작동 확인은 별개입니다. 자세한 범위는 ZIP의 `docs/scenarios.md`와 사용설명서를 확인하세요.

검증: 자동 테스트 278개 통과. 브라우저에서 정상 종료·수동 중지·임계온도 중단 → 대기 전환, 새 실험, 새로고침, 이전 결과 ZIP 다운로드와 모바일 배치를 확인했습니다. 실제 NI 장치 동작 검증은 클라우드에서 수행하지 않았습니다.
