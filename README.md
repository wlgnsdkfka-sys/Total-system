## 3번 탭에서 오래 측정하며 3분 안정 온도로 보정

**온도 입력 선택 → 보정용 온도 측정 시작 → TC1~12의 연속 180초 안정 확인 → 평균을 기준값으로 선택 → 보정 저장** 순서입니다.

- TC1~12 원시온도 그래프와 채널별 현재 값·구간 평균·표준편차·최대−최소를 실시간 표시합니다.
- 기본 안정 조건은 **최근 180초의 모든 TC1~12에서 σ ≤ 0.1°C, 최대−최소 ≤ 0.5°C**입니다. 시간은 180~3600초, 허용값은 측정 전에 조정할 수 있습니다. 초기값은 변경 가능한 예시입니다.
- 3분 미만이거나 한 채널이라도 불안정하면 새 기준 구간을 선택할 수 없습니다. 실제 비등 여부는 사용자가 확인합니다.
- **5분 제한 없이 계속 측정**합니다. 안정화돼도 자동 종료하지 않습니다. 보정 저장·ZIP 내보내기·브라우저 새로고침·탭 전환 중에도 서버의 수집을 계속합니다.
- 보정용 입력은 레이저 index **−1%**를 유지하며 출력 제어 실험과 동시에 시작하지 않습니다. 실제 레이저·셔터 출력 명령은 보내지 않습니다.

안정 조건을 만족하면 **안정 180초 평균을 기준값으로 선택**을 눌러 해당 구간과 평균을 고정합니다. 기본 기준온도 **100°C**를 확인하고 아래 **기준온도에 맞춰 보정 저장**을 누르세요. 이후 원시온도에 채널별 오프셋을 더하며, 보정 수집의 안정 판정에는 오프셋을 적용하지 않습니다. 보정값은 표에서 미리보고 다음 출력 제어 실험부터 사용합니다.

기본 저장은 측정 근거가 있어야 합니다. 기존 단일 샘플·30초 CSV·직접 입력은 유지하지만 ‘고급 · 수동 기준 사용’을 명시적으로 선택할 때만 미검증 수동 보정으로 저장합니다.

## NI 장비에서 직접 원시온도 읽기

NI-DAQmx 드라이버와 Python 패키지가 필요합니다. 측정 PC에서 프로그램 폴더를 열고 다음 명령을 실행합니다.

```sh
python -m pip install -r requirements-ni.txt
```

3번 탭의 **NI 열전대 · 실제 입력**을 선택하고 물리 채널과 실제 열전대 종류를 TC1~12 모두 지정하세요. 모두 같으면 전체 선택, 다른 채널은 개별 변경을 사용합니다. 제공 VI의 참조 후보는 TC1~8 `cDAQ1Mod3/ai0~ai7`, 벌크 TC9~12 `ai15/ai14/ai13/ai12`이며 실제 배선과 대조해 수정해야 합니다. 종류는 임의로 가정하지 않고 선택하도록 두었습니다. 냉접점은 모듈 내장, 온도 범위는 기본 0~300°C이며 수정할 수 있습니다.

동일한 NI 장치를 사용하는 TC JHK.vi 등 기존 측정을 중지한 뒤 시작하세요. NI는 실제 시각의 1배속으로 약 1초 간격 수집을 수행합니다. 잘못된 값·2초 초과 누락·드라이버 오류는 수집을 중단하고 해당 구간의 새 기준 선택을 막습니다. 온도 AI 읽기만 수행하고 레이저·셔터 출력을 생성하지 않습니다. 실제 발진 OFF·셔터 상태는 기존 장치에서 직접 확인하세요.

NI 없이 가상 비등 온도와 CSV로 미리 확인할 수 있습니다. 가상/CSV의 배속은 데이터 시각을 가속하는 시험 기능이며 실제 3분을 기다렸다는 뜻이 아닙니다. 실제 NI에는 배속을 적용하지 않습니다.

## 원시데이터와 보정 근거 보관

`results/calibration_날짜_시간_ID/`에 전체 원시온도를 계속 저장합니다. 그래프는 최근 최대 15분을 보여줍니다.

**측정 원시데이터 ZIP 저장**에는 `capture.json`(NI 입력·안정 기준·시각), 전체 `raw_samples.csv`, 이벤트와 각 선택 구간의 `reference_ID.csv/json`이 들어 있습니다. 선택한 구간의 12채널 평균·σ·변동폭·샘플 수·SHA-256도 보관합니다. ZIP은 완성된 행까지의 스냅샷이며 압축 중 입력 잠금을 잡지 않습니다.

보정 설정 JSON과 이후 실험의 `run.json`에도 선택 근거를 보관합니다. 여러 구간을 선택해도 각각 별도 ID와 파일을 남기고 이전 실험 결과를 덮어쓰지 않습니다. 일반 중지·CSV 종료 시 마지막 구간이 안정 상태라면 선택할 수 있습니다. Esc/긴급중단·오류로 끝나면 종료 구간의 새 선택을 막습니다.
