온도 추이와 실시간 온도 표준편차는 같은 시작·끝과 같은 시간 눈금을 사용합니다. 기본 표시는 최근 120초입니다. 두 그래프 아래의 **두 그래프 공통 시간 범위**에서 다음을 선택합니다.

- 최신 데이터 따라가기: 표시할 초를 입력하거나 30초·1분·2분·5분·10분·30분 버튼을 누릅니다.
- 전체 시간: 현재 실행의 모든 온도와 표준편차 이력을 함께 봅니다.
- 시작·끝 직접 지정: 첫 측정을 0초로 한 경과 초를 입력하고 적용합니다.

표시 범위를 바꿔도 표준편차는 매 시점의 직전 30초로 계산합니다. 시간 범위 설정은 측정·안정화·차단 판정을 변경하지 않습니다. 샘플 사이의 표시 경계는 선만 보간하며 원래 데이터를 변경하지 않습니다. 기록 행을 누르면 두 실시간 그래프가 그 기록의 20초로 함께 이동합니다. 단계별 σ 보기의 X축은 출력(%)이며, 시간 범위를 적용하면 실시간 보기로 돌아옵니다.

표시 설정은 현재 브라우저 창의 새로고침에도 유지됩니다. 전체 TC1~8·σ 이력은 실행 중 메모리에 보관하며 프로그램 종료 후 복원하지 않습니다. 저장 CSV는 계속 단계별 선택 구간을 보관합니다.
