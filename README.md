기존 측정을 종료하고 결과를 저장한 뒤 화면 오른쪽 위 **프로그램 종료** 또는 기존 실행 창 Ctrl+C로 완전히 종료하세요. ZIP을 모두 풀고 `실행하기.bat`를 실행해 상단 **TC / JPT v21**을 확인하세요. 기존 보정·설정·기록을 유지하려면 `results` 폴더를 유지하세요. Python 3.10 이상이 필요하며 NI 입력에는 NI-DAQmx 드라이버와 `requirements-ni.txt` 패키지가 필요합니다.

v21 변경 사항:

- **출력 단계 상승 시 330 Hz 낮은음 한 번**을 재생합니다. 기존 표준편차 경보는 660 Hz·2회, 임계 경보는 1100 Hz·3회로 유지합니다. 상단 **출력 상승음 시험**으로 확인할 수 있으며 비프음 끄기는 모두 끕니다. 같은 상태 재수신·새로고침·소리 재활성화로 과거 상승음을 반복하지 않습니다. 실제 레이저 통신은 미연결이며 상승음은 프로그램의 출력 단계 증가 알림입니다.
- **CSV 세 파일을 묶어서 저장**합니다. LVM도 텍스트이므로 확장자 변경 대신 매 샘플 쓰기/flush를 줄였습니다. 다음 입력에서 0.25초 경과 또는 128행 도달 시 저장하고, 출력 상승·단계 기록·중단·정상 종료·다운로드 전에도 남은 데이터를 비웁니다. 원시/4번 보정/3번 최종 CSV와 숫자 정밀도·전체 샘플을 유지합니다.
- 저장 실패 시 세 파일을 같은 이전 완료 지점으로 되돌리고 중단합니다. 강제 종료에서는 마지막 미저장 구간이 남을 수 있습니다. 화면에 입력 수와 저장 완료 수를 함께 표시합니다. NI 버퍼 2초 보호 정지는 유지합니다.

기존 셔터 수동제어 복귀, 전기로 자동/수동 보정, 대기 상태로 버튼, TC 두 자리 표시, 레이저 GUI Ctrl 요청 모드·기본 0 kHz / 1 ns, 연결 복구 기능을 유지합니다. 실제 레이저 OFF·출력 설정·ON과 장비 모드 조회는 여전히 미연결입니다.

검증: 자동 테스트 289개와 브라우저 시험을 통과했습니다. Web Audio 신호에서 330/660/1100 Hz, 상승당 1회·음소거·과거 이벤트 반복 방지를 확인했습니다. 10,000샘플 건별/묶음 저장 시험에서 CSV SHA-256이 같고 명시적 flush 호출은 30,000회 → 237회, 저장 처리 중앙값 기준 속도는 약 1.27배였습니다. 저장 처리 시험이며 측정 PC나 NI 전체 지연의 개선율을 뜻하지 않습니다. `python tools/benchmark_storage.py`로 PC에서 비교할 수 있습니다. 실제 장비 동작과 PC 소리는 클라우드에서 검증하지 않았습니다.
