## 비프음 끄기와 OFF index

실험 화면의 **임계온도·표준편차 표시등 옆 ‘비프음 끄기’**를 누르면 모든 경보음을 끕니다. 측정 시작 전에도 끌 수 있고 다음 실험에서도 유지합니다. 모든 탭 상단의 **소리 켜기 / 소리 시험**으로 다시 켤 수 있습니다. 현재 경보만 음소거하는 기존 버튼도 유지합니다.

레이저 index는 **완전 OFF = −1%, 발진 ON의 출력 설정 = 0~100%**로 구분합니다. 시작 대기·중지·임계온도 중단·출력 상한 완료는 −1%입니다. 0%에서도 출력이 나오는 장비 특성을 반영했습니다. 단계 기록은 발진 ON이었던 0~100%를 유지하고, 종료 이벤트에 OFF index와 직전 설정을 함께 남깁니다. −1은 내부 OFF 표기이며 장비에 전송하는 음수 출력 명령이 아닙니다.

## 새 3번 탭: 온도 보정

탭 순서는 **실험 / 보일링 커브 / 온도 보정 / 수식·상수 설정**입니다. 기존 3번 탭의 포화온도·계산식·누수 의심 설정은 4번 탭으로 옮겼습니다.

모든 TC를 같은 끓는 물에서 충분히 안정화한 뒤, TC1~8과 벌크 TC9~12의 원시온도를 **3번 탭**에서 불러오세요. 기본 기준은 **100°C**이며 변경할 수 있습니다.

- 직접 입력, **최근 원시값 불러오기**, **비등 기준 CSV 불러오기**를 제공합니다.
- CSV는 `t_s,TC1,...,TC12` 열, 최소 두 샘플, 증가하는 시각과 최대 2초 간격이 필요합니다. 마지막 최대 30초 평균과 확보 시간·샘플 수·최대 표준편차를 표시합니다.
- 채널별 **보정값 = 기준온도 − 비등 시 원시온도**, 이후 **온도 = 원시온도 + 보정값**입니다. 예를 들어 기준에서 98°C이면 +2°C를 적용하며 이후 110°C는 112°C가 됩니다. 1점 오프셋 보정입니다.
- **기준온도에 맞춰 보정 저장**은 실험을 중지한 상태에서 누릅니다. 저장·해제·초기화는 다음 실험부터 적용하고, 이전 기록과 마지막 측정값은 당시 보정을 유지합니다.
- 같은 프로그램 폴더의 `results/temperature_calibration.json`에 저장해 다음 실행에서도 유지합니다. 보정 설정 JSON 저장도 제공합니다.

보정 온도는 TC 그래프·표·표준편차·임계온도 판정·열유속 계산과 벌크 실시간 값에 반영합니다. 임계온도는 평균하기 전의 각 보정 샘플로 판정합니다. 4번 탭의 포화온도는 별개이며 자동 변경하지 않습니다.

`run.json`에 실험 당시의 보정 ID·기준값·원시 기준값 12개·오프셋·출처·시각을 보관합니다. `selected_samples.csv`의 `TC1..TC12`는 보정 온도이고 `TC1_raw_c..TC12_raw_c`는 원시온도입니다. 이 앱에서 내보낸 CSV를 다시 가져올 때 원시 열을 우선해 중복 보정하지 않습니다. 원본 CSV와 이전 결과를 덮어쓰지 않습니다.
