## v4 화면

첫 번째 탭 맨 위에 실험 설정을 가로로 놓았습니다. 아래에는 **실시간 TC 온도 추이 | 온도 표준편차 | TC9~12 벌크 온도**를 한 줄에 표시합니다. 1366×768 화면에서도 세 패널을 함께 볼 수 있게 높이를 조정하고, 작은 모바일 화면에서는 세로로 배치합니다.

표준편차 그래프는 현재 출력의 최근 20초 σ(N−1)를 실시간 표시합니다. 메뉴를 바꾸면 기존의 단계별 기록 σ를 볼 수 있습니다. 출력 변경 뒤에는 새 자료를 20초 모으며 이전 단계와 섞거나 빈 구간을 선으로 연결하지 않습니다. PNG 저장과 TC1~8 채널 선택도 지원합니다.

## W/cm² 기준 입력 없이 감지

3번째 탭에서 **열유속 σ 임계값**과 **비교 기준 최소 열유속** 입력란을 없앴습니다. 처음 채운 감시 구간의 흔들림으로 자동 기준을 잡고, 경고가 없던 완료 단계의 선택 구간으로 갱신합니다. 민감도(기준 σ의 3/5/8배)를 선택할 수 있습니다. 감소율(%)을 선택 입력하면 출력 상승 후 감소도 함께 감시하며, 비교할 최소 열유속은 이전 단계 잡음으로 자동 계산합니다.

처음부터 이상이 있는 자료는 정상 기준으로 오인할 수 있습니다. 자동 기준과 배수는 실제 실험에서 검증된 누수 검출 기준이 아닙니다. 열유속 요동·감소는 비등 변화 등에서도 생기므로 **누수 의심 / 열전달 이상**으로 표시합니다. 초기에는 감지가 꺼져 있고 기본 동작은 경고입니다. 중단 판정을 선택하면 다음 출력 상승 전에 두 가상 차단 요청을 기록합니다.

TC9~12와 네 채널 평균은 참고값으로 표시하며 포화온도를 자동 변경하지 않습니다. TC1~8 그래프·단계별 표·안정화·임계온도 판정은 유지합니다. 두 번째 보일링 커브 탭과 세 번째 계산식·상수·포화온도 설정, CSV/ZIP/PNG 저장도 사용할 수 있습니다.
