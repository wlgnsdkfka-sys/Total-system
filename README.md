# TC / JPT GUI v13

[**수정된 GUI v13 ZIP 다운로드**](https://github.com/wlgnsdkfka-sys/Total-system/raw/refs/heads/gui-download-20261021/downloads/TC_JPT_GUI_v13.zip)

**같은 실험의 4번 전기로 보정까지만 적용한 데이터와 3번 실험 오프셋까지 적용한 데이터를 서로 다른 CSV에 동시에 저장**합니다. 보정 전 원시온도도 세 번째 CSV로 보관해 나중에 다시 가공할 수 있습니다.

## 별도로 저장하는 파일

| 파일 | TC1~8 | bulk TC9~12 |
|---|---|---|
| `measurements_raw.csv` | 보정 전 원시온도 | 보정 전 원시온도 |
| `measurements_tab4.csv` | 전기로 보정만 적용 | 원시온도 |
| `measurements_tab3.csv` | 전기로 보정 + 실험 오프셋 | 원시온도 + 비등 오프셋 |

세 파일에 **같은 sample_id·시각·출력**으로 전체 처리 샘플을 저장합니다. 20초 선택 구간에만 한정하지 않고 첫 단계가 끝나기 전 중지해도 데이터를 보관합니다. 임계온도를 넘어 중단을 유발한 입력 샘플도 남깁니다. 보정을 사용하지 않은 단계는 이전 단계와 같은 값으로 저장합니다.

1번 탭 아래 **보정 단계별 데이터 저장**에서 원시 / 4번까지만 / 3번 오프셋까지 CSV를 각각 내려받을 수 있습니다. 앱은 `results/run_날짜_시간_ID/`에도 세 파일을 자동 저장합니다. 새 실험부터 생성하며 과거 실험 파일은 유지합니다.

## 같은 구간으로 비교하고 나중에 재처리하기

상단 **결과 ZIP 저장**에는 세 CSV와 당시 보정식·교정점·오프셋·상수·이벤트를 함께 담습니다. 측정 중 ZIP은 세 파일을 같은 마지막 행까지 고정하고 수집을 계속합니다. 개별 CSV는 각각 클릭한 시점까지 포함하므로 실험 중 따로 누르면 행 수가 달라질 수 있습니다. 같은 종료 시점이 필요하면 ZIP 또는 측정 종료 후 개별 저장을 사용하세요.

CSV 온도 열은 공통 `TC1`~`TC12`이고 단위는 °C입니다. `temperature_basis`로 raw / tab4 / tab3를 표시합니다. `sample_id`로 같은 입력을 비교할 수 있습니다. `t_s`는 입력 시각, `elapsed_s`는 해당 실험의 경과 초입니다. `power_percent`는 샘플의 단계 출력, `power_index_after_sample_percent`는 그 샘플 판정 후 index입니다. 원시 bulk 누락값은 빈칸으로 유지합니다.

`run.json`에는 시작 시 고정한 전기로 보정식·원시 교정점·비등 원시 기준·채널별 오프셋·5번 수식 상수가 있습니다. `DATA_FORMAT.md`에는 열과 저장 범위를, ZIP의 `data_snapshot.json`에는 포함된 샘플 수·CSV별 바이트 수를 기록합니다. 같은 온도 이력을 다른 보정식이나 상수로 다시 가공할 때 함께 보관하세요.

앱에서 CSV를 재생해 다시 처리할 때는 **measurements_raw.csv**를 사용합니다. 이미 보정된 CSV만 원시 입력으로 넣어 중복 보정하는 경우를 차단합니다. 기존처럼 `TC1_raw_c`~`TC8_raw_c` 원시 열을 포함한 파일은 원시 열을 사용합니다.

## 유지하는 기능

- 기존 `stages.csv` 평균·표준편차와 `selected_samples.csv`의 선택된 20초 기록은 유지합니다.
- selected_samples에는 기존 최종 TC·원시 TC 열 뒤에 `TC1_tab4_c`~`TC12_tab4_c`를 추가해 그 구간도 세 단계로 비교할 수 있습니다.
- 4번 전기로 교정은 TC1~8만 사용합니다. bulk TC9~12는 3번의 100°C 비등 오프셋만 적용하고 이후 변화를 실시간으로 표시합니다.
- 기본 2번 커브와 임계온도·안정화 판정은 최종 보정온도를 사용합니다. 단계별 자동 커브와 수동 데이터 보호를 유지합니다.
- 실험 중 저장한 5번 상수는 다음 실험부터 적용하며 현재 실험은 시작 당시 상수를 유지합니다. 최신 저장 상수로 기존 기록을 재계산할 수도 있습니다.

## 실행·데이터 이동·검증

이전 앱을 종료하고 ZIP을 모두 푼 뒤 **`TC_JPT_GUI/실행하기.bat`**를 실행하세요. Python 3.10 이상이 필요합니다. 가상·CSV에는 별도 패키지가 없고 NI 교정용 입력에는 NI-DAQmx와 `python -m pip install -r requirements-ni.txt`가 필요합니다.

기존 교정 설정을 옮기려면 앱을 종료한 상태에서 이전 `results/temperature_calibration.json`, `initial_calibration_data.json`, `calculation_settings.json`, 필요하면 `leak_settings.json`을 새 폴더의 `results`로 복사합니다. 기존 초기 데이터 JSON/CSV를 4번에서 불러와 계산·적용할 수도 있습니다.

사용법은 ZIP의 **`docs/measurement_data.md`**, 전체 순서는 **`docs/workflow.md`**에 있습니다.

자동 검사 **211개**와 압축 해제한 배포본 검사를 통과했습니다. 비단위 보정 기울기·오프셋이 있는 세 파일 값, 전체 행 정렬, 전이 출력·종료 index, 조기 중지·임계온도 샘플, 선택 구간 보간점, 누락 bulk, 데이터 저장 오류 시 정렬·중단, 측정 중 ZIP 압축과 입력 지속, 원시 재생과 중복 보정 차단을 확인했습니다. Chromium에서 세 CSV 각각 다운로드, 측정 중 ZIP, 20초 기록 호환, 전체 교정·자동 커브 흐름과 모바일을 확인했습니다. 실제 AudioContext 신호로 기존 비프음·음소거·임계온도 즉시 변경·긴급중단도 확인했습니다.
