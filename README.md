## 임계온도 수정과 비프음

측정 중 **임계온도**를 입력하고 **적용** 또는 Enter를 누르세요. 적용 전에는 기존 적용값으로 계속 감시합니다. 새 임계값 이상인 TC가 있으면 최신 원시값으로 즉시 중단을 판정합니다. 출력·측정 시간·통계·기록은 초기화하지 않습니다. 중단한 실험은 값을 올려도 자동으로 재개하지 않습니다. 변경 전후 값과 측정 시각은 `events.jsonl`에 남으며 `run.json`은 시작 당시 설정을 보관합니다.

상단 **소리 시험**으로 시험음을 확인하세요. 측정 시작 또는 소리 켜기 클릭으로 브라우저 오디오를 활성화합니다.

- 임계온도 경보: 높은 음 3회, 2초 간격 반복. 중단 후에도 유지합니다.
- 표준편차 초과: 낮은 음 2회, 5초 간격 반복. 측정 중 최근 30초 기준이며 정상 복귀 또는 측정 종료 시 멈춥니다.
- 두 조건이 겹치면 임계온도가 우선입니다. 다른 탭에서도 알림을 처리합니다.
- **현재 알림 음소거**는 현재 경보가 지속되는 동안 소리를 멈춥니다. 정상 복귀 후 재초과하거나 임계온도 경보가 새로 발생하면 울립니다.
- **소리 끄기**는 모든 비프음을 끄며 같은 창의 새 실험에서도 유지합니다. 소리 켜기/소리 시험으로 다시 켜세요. 새로고침 후에는 클릭으로 다시 활성화해야 합니다.

소리가 안 들리면 PC 음량·출력 장치·브라우저 탭/사이트 음소거를 확인하세요. 소리 활성화 실패 상태는 화면에 표시합니다. 브라우저와 운영체제의 절전·백그라운드 제한에 따라 알림이 지연되거나 들리지 않을 수 있습니다. 소리 오류는 서버의 온도 판정과 기록을 막지 않습니다.
