## v3 변경 내용

- TC9~12 벌크 온도와 네 채널 평균을 단계별 표 옆에 실시간 표시합니다. 없는 값은 —로 표시하며, 그래프·단계별 표·안정화·임계온도 판정은 TC1~8을 사용합니다. 벌크 온도는 포화온도 참고값이며 포화온도 설정은 자동 변경하지 않습니다.
- 최근 구간의 열유속 표준편차 또는 출력 상승 후 이전 단계 대비 열유속 감소율로 **누수 의심 / 열전달 이상**을 감시합니다. 비등 상태 변화 등에서도 생기는 신호이므로 누수 확정 판정은 아닙니다.
- 세 번째 탭에서 임계값, 비교 최소 열유속, 대기·감시·지속시간과 경고/중단 동작을 설정·저장합니다. 초기에는 감지가 꺼져 있으며, 계산식과 기준 확인 후 켤 수 있습니다. 중단 옵션은 다음 출력 상승을 막고 두 가상 차단 요청을 기록합니다.
- 경고는 모든 탭에서 보이며, 실행별 감지 설정·계산식과 의심 시각·조건·측정값을 결과에 보존합니다. CSV의 선택 구간에는 TC9~12도 보존합니다.
- v2의 최신순 기록, 표준편차 그래프, 보일링 커브와 수식·상수·포화온도 설정을 유지합니다.

## Windows 실행

Python 3.10 이상을 설치한 뒤 ZIP 압축을 모두 풀고 `TC_JPT_GUI/실행하기.bat`를 더블클릭하세요. 별도 Python 패키지는 필요하지 않습니다. 자세한 설명은 ZIP 안의 `사용설명서.txt`에 있습니다.

감지는 **03 · 수식 / 상수 설정 → 누수 의심 / 열유속 이상 감지**에서 설정합니다. TC 대응·열유속 계산식·부호를 실제 VI 결과와 대조하고, 실험에 맞는 임계값을 직접 입력하세요. 기본 상수는 VI 도면의 참고값입니다. 현재 프로그램이 실제 VI와 동일하게 계산한다고 검증한 상태는 아닙니다.
