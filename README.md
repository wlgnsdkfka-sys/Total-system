# TC / JPT GUI v17

[**GUI v17 다운로드**](https://github.com/wlgnsdkfka-sys/Total-system/raw/refs/heads/gui-download-20261021/downloads/TC_JPT_GUI_v17.zip)

브라우저만 닫아 NI 카운터를 소유한 Python 프로그램이 남는 경우를 다룹니다. **v17 이후는 실행 중인 GUI를 확인하고 재사용**해 중복 서버가 myDAQ1 카운터를 점유하지 않도록 합니다. 종료 시 연결 감시를 먼저 중지하고 소유 태스크를 해제합니다.

처음 업데이트할 때는 잠금 기능이 없던 **이전 v16을 프로그램 종료 버튼 또는 실행 창 Ctrl+C로 한 번 종료**해야 합니다. 브라우저만 닫으면 기존 프로그램은 계속 실행됩니다. 이후 기존 results 폴더를 새 프로그램 폴더에 복사해 설정·교정·기록을 유지하세요.

7번의 **셔터 연결 복구**는 소유한 태스크를 해제하고 연결을 다시 만듭니다. 유효하지 않은 태스크 −200088은 재사용하지 않습니다. 장치 전체 리셋이나 다른 프로그램의 태스크 강제 해제, 이전 열림 파형 재개는 하지 않습니다. 카운터 예약 오류 −50103은 이전 프로그램 점유를 확인해야 합니다.

## 실제 자동실험 시나리오 점검

**현재 실제 레이저 OFF·출력 설정·ON 통신과 자동 시작 초기화는 미연결/미구현입니다.** NI 온도 측정 시작을 실제 자동출력 실험 시작으로 취급하면 안 됩니다. 7번에 목표 순서와 현재 구현을 나란히 표시하고 실제 자동실험 시작은 준비 미완료로 표시합니다.

| 동작 | 현재 |
|---|---|
| TC1~8 임계온도 이상 판정 | 지원 |
| 연결된 NI 셔터 닫기 요청 | 지원, 실제 위치 피드백은 없음 |
| 실제 레이저 발진 OFF | 미연결, 소프트웨어 index −1%와 구분 |
| 수동 상태에서 실제 0% 초기화 후 자동 시작 | 미구현 |
| 셔터 자동 열기 → 레이저 ON(0%) → 단계 시작 | 미구현 |
| 단계별 기록·가상 출력 일정 | 유지, 실제 출력 명령은 미연결 |

요청한 목표는 TC 정상 수신 확인 → 실제 OFF/셔터 닫기 → 실제 0% 설정 응답 확인 → 셔터 열기 → 실제 ON(0%) → 단계 시간 시작입니다. 수동 고출력을 남긴 채 셔터부터 자동으로 여는 임시 동작을 추가하지 않았습니다. 임계온도에서는 실제 셔터 닫기와 레이저 OFF가 독립적으로 동작해야 하며 레이저 연결이 다음 구현 단계입니다.

자세한 목표 순서와 수동 50%·고온 시작·통신 실패 점검 사례는 ZIP의 `docs/scenarios.md`에 있습니다.

## 유지 기능·검증

일곱 탭, 장치 통신 표시등, myDAQ1 연결 복원, 고해상도 교정·초기 2초 제외, 고속 NI 입력과 세 보정 단계 CSV 저장은 유지합니다. 셔터 파형은 열림 HIGH 1.0ms / 닫힘 HIGH 1.5ms / LOW 18.5ms 고정입니다. 레이저 버튼은 연결 준비 상태입니다.

검사 **272개**와 압축 해제 배포본 검사를 통과했습니다. 실제 로컬 HTTP 서버의 중복 실행 재사용·종료 잠금 해제, 인스턴스 확인, 소유 태스크 복구와 무출력 재연결, 기존 교정·기록·차단 요청을 검사했습니다. Chromium에서 시나리오 표시·준비 미완료 버튼, 셔터 복구·연결/수신 표시·설정 복원·모바일을 확인했습니다. NI 검사는 드라이버 대역이며 실제 Windows/myDAQ 재실행과 기계적 동작은 PC에서 확인해야 합니다.
