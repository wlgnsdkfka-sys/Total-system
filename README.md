- **측정 중 전체 시각의 원시/4번/3번 온도는 LVM 세 파일에만 연속 저장합니다.** 단계 요약 CSV 본문 작성은 온도 입력 태스크 종료 후로 옮겼습니다. 측정 중 화면·이력·표·커브 반영은 유지합니다.
- CSV 변환·연속 LVM 변환·ZIP 생성·기존 파일 정리는 실험/보정 수집과 종료 정리가 모두 끝난 뒤에 사용합니다. 파일 변환 중 새 측정도 차단해 CPU·디스크 경합을 줄입니다. 후처리용 CSV는 종료 후 계속 사용할 수 있습니다.
- **4번 전기로 보정의 안정 확인 시간을 10~3600초로 설정**합니다. 기본은 180초이며 화면·안정 근거 검증·보정점 추가·계산·적용·저장·불러오기에 반영했습니다. 3번 실측보정도 같은 범위입니다.
- 정지·재시작과 NI 입력 해제 경합, 파일 종료 오류 시 다른 파일을 닫지 못하던 경로, 요약 CSV 부분 쓰기, 마지막 저장 오류 표시, run.json의 오래된 파일명, 불완전한 LVM 구간·중복 CSV 온도 열 처리를 고쳤습니다. 패키지 `docs/review_v24.md`에 점검 내용을 담았습니다.
