# TC / JPT GUI v14

[**GUI v14 ZIP 다운로드**](https://github.com/wlgnsdkfka-sys/Total-system/raw/refs/heads/gui-download-20261021/downloads/TC_JPT_GUI_v14.zip)

**3·4번 교정은 고해상도, 1번 NI 온도 입력은 고속 모드**로 수집합니다. 교정 시작 시 첫 2초와 최초 샘플을 그래프·원시 기록·안정 판정에서 제외하며, 이후 연속 180초를 새로 확보합니다.

| 용도 | ADC 모드 | 수집 방식 |
|---|---|---|
| 4번 전기로 교정 / 3번 비등 오프셋 | HIGH_RESOLUTION | 약 1초 간격 목표, 첫 2초와 최초 샘플 제외 |
| 1번 NI 실측 | HIGH_SPEED | 현재 채널 구성의 지원 최대 속도로 하드웨어 연속 수집 |

실험에서는 DAQmx에서 최대 지원 속도를 조회해 연속 시계를 구성하고, 최종 설정된 실제 속도를 회/초/채널로 표시합니다. 샘플 번호와 하드웨어 설정 속도로 시각을 계산합니다. 화면 갱신과 별도로 모든 처리 샘플을 수집·판정·저장하며, NI 입력에 재생 지연이나 1초 대기를 추가하지 않습니다.

기존 세 CSV `measurements_raw.csv`, `measurements_tab4.csv`, `measurements_tab3.csv`와 선택한 20초 구간·단계별 평균/표준편차·자동 커브를 유지합니다. `run.json`에는 새 ADC 모드·속도·NI 채널 설정을 남깁니다. 범위 오류에는 해당 TC·물리 채널·값·설정 범위를 표시합니다. NI 수집의 읽기/버퍼 지연과 파일 오류는 실행을 중지합니다.

## 안정 확인 후 저장·적용

- **4번 전기로:** 기준온도 입력 → 3분 안정 → **현재 안정 3분 평균을 측정점으로 추가**. 여러 온도에서 반복한 뒤 **보정식 계산 → 계산한 초기 보정식 적용**. TC1~8만 교정하고 bulk는 제외합니다.
- **3번 실험 오프셋:** 물이 실제로 끓는 상태에서 3분 안정 → **안정 180초 평균을 기준값으로 선택** → 기준온도 확인(기본 100°C) → **기준온도에 맞춰 보정 저장**. 저장값은 다음 실험부터 자동 적용합니다.
- **보정 설정 JSON 저장**은 별도 백업입니다. 적용 버튼과 구분하며 원시데이터 ZIP도 함께 보관하세요.

선택한 안정 구간은 고정하고 저장 전 미리보기와 저장된 보정을 구분합니다. 안내 문구를 개선하고 안정 평균을 선택하면 저장 버튼 위치로 이동합니다. 4번 초기 보정 뒤 3번 오프셋을 더하는 기존 순서와 bulk의 독립적인 100°C 비등 오프셋을 유지합니다.

## 실행·업데이트

기존 앱을 종료하고 ZIP을 모두 푼 뒤 `TC_JPT_GUI/실행하기.bat`를 실행합니다. Python 3.10 이상이 필요합니다. NI에는 NI-DAQmx와 `python -m pip install -r requirements-ni.txt`가 필요합니다.

이전 `results` 폴더를 새 프로그램 폴더에 복사하면 교정점·초기 보정식·비등 오프셋·상수와 이전 결과를 유지할 수 있습니다. 새 실험은 새 결과 폴더에 저장됩니다. 자세한 설명은 ZIP의 `docs/ni_sampling.md`와 `docs/workflow.md`를 참고하세요.

현재 연결이 확인된 구성은 NI-9213 `cDAQ1Mod3`, cDAQ-9174, K타입 TC1~12입니다. **실제 레이저·셔터 출력 제어는 미연결**입니다. 1번에서 실제 온도를 수집해도 출력 index·단계 진행·차단 요청은 가상 일정이며 저장된 power_percent는 실제 측정 광출력이 아닙니다.
