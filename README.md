## v5 변경

- **실시간 온도 표준편차:** 각 시점 직전 30초의 TC1~8 표본 표준편차(N−1)를 실험 전체 시간에 걸쳐 그립니다. 출력 변경 시에도 이동창과 그래프를 이어 갑니다. 처음 30초 미만은 확보된 데이터로 계산하며, 첫 샘플만 있을 때는 계산하지 않습니다. 기록 모드에서는 기존에 선택한 단계별 20초 구간의 σ를 볼 수 있습니다.
- **두 표시등:** 임계온도 이상과 30초 표준편차 설정값 초과를 각각 표시합니다. 정상 초록 / 초과 빨강 / 초기 수집·데이터 오류 노랑 / 미설정 회색입니다. 그래프에서 숨긴 TC도 판정합니다. 종료 후에는 마지막 값임을 표시합니다.
- **출력별 90~300초:** 최소 1분 30초 뒤부터 최근 30초의 모든 TC σ가 허용값 이하일 때 조기 상승합니다. 최대는 5분입니다. 임계온도·오류·긴급중단·선택한 누수 의심 중단은 90초 이전에도 우선 적용합니다.

출력 상승 직전 최근 60초에서 고르는 공통 20초의 평균·σ 기록은 유지합니다. v4의 상단 가로 설정, 온도·표준편차 그래프와 오른쪽 벌크 온도, 자동 열유속 이상 감지 기준, 보일링 커브와 수식·상수 설정, CSV/ZIP/PNG 저장도 유지합니다. 벌크 온도는 포화온도 참고값이며 포화온도를 자동 변경하지 않습니다.

Python 3.10 이상을 설치하고 압축을 모두 푼 뒤 `TC_JPT_GUI/실행하기.bat`를 더블클릭하세요. 별도 Python 패키지는 필요하지 않습니다. `사용설명서.txt`에 사용법이 있습니다.
