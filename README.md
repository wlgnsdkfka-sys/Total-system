# TC / JPT GUI v10

[**GUI v10 ZIP 다운로드**](https://github.com/wlgnsdkfka-sys/Total-system/raw/refs/heads/gui-download-20261021/downloads/TC_JPT_GUI_v10.zip)

4번 탭에 **초기 온도 Calibration**을 추가했습니다. 99·100·110·120·130°C 등 여러 기준온도의 TC1~12 원시온도 측정점을 저장·불러오고, 채널별 `T_initial = a × T_raw + b` 보정식을 계산·적용합니다. 기존 수식·상수·포화온도와 누수 의심 감시 설정은 **5번 탭**으로 옮겼습니다.

## 사용 순서

1. 3번 탭에서 NI 열전대 또는 가상/CSV 원시온도 연속 측정을 시작합니다.
2. 기준 온도계·교정기로 실제 온도를 확인하고, 모든 TC가 그 온도에서 연속 3분 이상 안정될 때까지 기다립니다.
3. 4번 탭에서 기준온도와 메모를 입력하고 **현재 안정 3분 평균을 측정점으로 추가**를 누릅니다. 기본 180초, 모든 TC1~12의 σ ≤ 0.1°C와 최대−최소 ≤ 0.5°C 조건이며 3번 탭에서 측정 전 수정할 수 있습니다.
4. 다음 기준온도에서 충분한 안정 구간을 확보한 뒤 반복합니다. 99~130°C 빠른 입력 외에 임의 온도를 입력할 수 있습니다. 수집은 탭을 바꿔도 계속합니다. 고급 입력에서 기존 12채널 측정값을 직접 입력할 수도 있습니다.
5. **보정식 계산 → 채널별 계수·RMSE·최대 잔차·R²와 그래프 확인 → 계산한 초기 보정식 적용** 순서로 사용합니다. 서로 다른 기준온도의 최소 2개 점이 필요하며 사용 범위를 포함한 3개 이상을 권장합니다.

점마다 같은 가중치의 1차 최소제곱 보정을 사용합니다. 그래프는 채널을 선택해 보정 직선과 잔차를 나란히 봅니다. 측정 범위 밖은 직선 외삽하며 온도를 제한하지 않습니다. 잔차는 입력점에 대한 차이이며 독립적인 정확도 검증값은 아닙니다.

## 저장 / 불러오기

- **데이터 JSON 저장 / 데이터 CSV 저장**: 측정점, TC1~12 원시 평균, 메모와 안정 구간 통계·근거를 파일로 내려받습니다. 앱 CSV도 근거를 유지해 다시 불러옵니다.
- **데이터 파일 불러오기**: 전체 파일을 검증한 뒤 현재 측정점 목록을 대체합니다. 잘못된 파일은 기존 목록·저장 파일·적용 중인 보정식을 변경하지 않습니다. 불러온 뒤 다시 계산·적용하세요.
- **자동 저장**: `results/initial_calibration_data.json`에 작업 데이터를 저장하며 같은 폴더에서 재실행하면 복원합니다. 적용본은 `results/temperature_calibration.json`에 저장합니다. 계산 미리보기는 프로그램 재시작 후 다시 계산합니다.
- **측정 근거**: 3번 탭의 **측정 원시데이터 ZIP 저장**도 함께 보관하면 원시 시계열·입력 설정·선택 구간 해시를 대조할 수 있습니다.

측정점은 최신 추가순으로 표시하며 수정·삭제할 수 있습니다. 기준온도·메모만 수정하면 구간 근거를 유지하고 원시온도를 바꾸면 수동 점으로 바뀝니다. 데이터 편집만으로 적용본은 바뀌지 않습니다.

## 기존 비등 보정과 연결

처리 순서는 **4번 초기 보정 → 3번 비등 오프셋 → 온도·표준편차·임계온도·표면온도·열유속 계산**입니다. 초기 보정 변경 시 저장된 비등 원시 기준으로 오프셋을 다시 계산해 기존 비등 기준온도를 유지합니다. 3번 탭의 비등 오프셋 해제·초기화는 초기 보정식에 영향을 주지 않습니다. TC9~12 bulk도 같은 보정을 사용합니다. 보정용 원시 수집과 안정 판정은 원시값으로 수행합니다.

실험 중 보정식 적용·해제는 잠기고 다음 실험부터 변경값을 사용합니다. 실험별 `run.json`에는 당시 전체 측정점과 계수를 고정하며, 결과 CSV에는 최종 보정 온도와 원시 `TC1_raw_c..TC12_raw_c`를 함께 남깁니다. 과거 실험 기록은 바꾸지 않습니다.

## 실행과 검증 범위

Python 3.10 이상을 설치하고 ZIP을 모두 풀어 `TC_JPT_GUI/실행하기.bat`를 실행하세요. 이전 프로그램을 먼저 종료하고 새 폴더에서 실행합니다. 기존 보정을 옮기려면 종료한 상태에서 이전 `results/temperature_calibration.json`을 새 폴더의 같은 위치에 복사할 수 있습니다. 자세한 사용법은 ZIP의 `docs/initial_calibration.md`, NI 설치 안내는 `docs/ni_calibration.md`에 있습니다.

가상·CSV는 Python 표준 라이브러리로 실행합니다. 실제 NI 보정 입력은 NI-DAQmx 드라이버와 `python -m pip install -r requirements-ni.txt`가 필요합니다. VI의 후보 채널 TC1~8 `cDAQ1Mod3/ai0~ai7`, TC9~12 `ai15/ai14/ai13/ai12`를 실제 배선과 대조하고 열전대 종류를 직접 선택하세요. NI는 실제 시각의 1배 측정이며 AI 읽기 전용입니다.

자동 검사 **169개**와 압축 해제한 배포본 검사를 통과했습니다. Chromium에서 다섯 기준온도의 180초 수집, 파일 저장·불러오기, 계수·그래프, 편집·적용본 분리, 비등 보정 연결, 실험 결과·원시값 보관, 새로고침·재실행 복원, 모바일을 확인했습니다. 기존 비프음·OFF index −1%, 임계온도 판정과 원시 수집도 유지합니다.
