# TC / JPT GUI v11

[**수정된 GUI v11 ZIP 다운로드**](https://github.com/wlgnsdkfka-sys/Total-system/raw/refs/heads/gui-download-20261021/downloads/TC_JPT_GUI_v11.zip)

전기로 초기 교정과 실제 실험 오프셋의 작업 흐름을 분리하고, 최종 보정온도에서 보일링 커브까지 자동으로 연결했습니다.

## 작업 순서와 수정 사항

1. **5번 탭 — 수식·상수 저장**: 보정 순서와 관계없이 저장합니다. 실험 실행 중에도 저장할 수 있고 진행 중 실험은 시작 당시 상수를 유지합니다. 변경값은 다음 실험부터 사용하며 화면에 적용 시점을 표시합니다.
2. **4번 탭 — 전기로 초기 Calibration**: 이 탭에서 NI/가상/CSV 온도 측정 시작·중지·원시 ZIP 저장을 직접 실행합니다. 99·100·110·120·130°C 등 각 기준온도에서 TC1~12의 연속 3분 안정 평균을 측정점으로 추가하고 보정식을 계산·적용합니다. 전기로 자체의 조작은 기존 장치에서 합니다.
3. **3번 탭 — 실험 조건 오프셋**: 실제 실험의 알려진 기준 상태(기본 비등 100°C)에서 4번 보정 후 잔차를 구해 채널별 일정한 오프셋을 더합니다. **최종온도 = 초기 보정온도 + 실험 오프셋**입니다. 4번 초기 보정의 기울기와 원본 측정점은 유지합니다.
4. **1번 탭 — 최종 온도로 측정·기록**: 최종 보정온도로 표시·표준편차·안정화·임계온도 판정과 열유속 계산을 수행합니다. 원시값과 당시 보정·상수 적용본도 함께 저장합니다.
5. **2번 탭 — 단계 기록 자동 커브**: 새 단계의 20초 기록이 저장될 때마다 커브와 표를 자동 갱신합니다. 기본은 실험 시작 당시 상수이고, **5번 탭 최신 저장 상수**를 선택하면 기존 기록을 새 상수로 재계산합니다. 진행 중 감시와 원본 기록은 유지합니다.

CSV·표 직접 편집·예시 데이터는 자동 반영을 꺼서 수동 데이터를 유지합니다. 자동 반영을 다시 켜면 현재 실험 기록으로 돌아옵니다. 새 실험을 시작하면 이전 자동 커브를 비우고 새 단계부터 표시합니다. 커브 ZIP에는 실제 사용한 상수·보정식·오프셋과 실험 출처를 포함합니다.

3번과 4번은 각자의 최근 측정 상태·설정·원시 ZIP을 보관합니다. 같은 NI 입력을 동시에 점유하지 않도록 한 번에 하나만 실행합니다. 다른 탭에서 수집 중이면 먼저 중지하세요. 수집은 탭을 바꿔도 계속합니다.

## 데이터 저장·불러오기와 실행

4번의 초기 교정 측정점 JSON/CSV 저장·불러오기, 자동 저장, 수정·삭제, 채널별 1차 최소제곱 보정식과 잔차 그래프를 유지합니다. 최소 2개 서로 다른 기준온도가 필요하고 사용 범위를 포함한 3개 이상의 점을 권장합니다. 기본 안정 조건은 최근 연속 180초의 모든 TC1~12에서 σ ≤ 0.1°C와 최대−최소 ≤ 0.5°C이며 측정 전 조정할 수 있습니다. 가상 전기로의 목표온도는 측정 시작 시 기준온도를 사용하므로 바꾸면 중지 후 다시 시작하세요.

Python 3.10 이상을 설치한 뒤 ZIP을 모두 풀어 **`TC_JPT_GUI/실행하기.bat`**를 실행합니다. 이전 프로그램은 먼저 종료하세요. 가상·CSV에는 별도 패키지가 필요하지 않습니다. NI 보정 입력은 NI-DAQmx 드라이버와 `python -m pip install -r requirements-ni.txt`가 필요하며 각 TC의 실제 물리 채널·열전대 종류를 선택해야 합니다.

기존 v10의 데이터 JSON/CSV와 적용본을 그대로 사용할 수 있습니다. 이전 앱을 종료한 상태에서 `results/temperature_calibration.json`, `initial_calibration_data.json`, `calculation_settings.json`과 필요하면 `leak_settings.json`을 새 폴더의 `results`로 복사하세요. 또는 4번 탭에서 기존 데이터 파일을 불러와 계산·적용합니다. 원시 ZIP과 과거 실험 폴더도 별도 보관하세요.

열유속 계산식·TC 대응·부호를 바꾸고 누수 의심 감지를 사용하는 경우 다음 실험 전 계산식을 확인하고 감지 설정을 다시 저장해야 합니다. 진행 중 감시는 시작 당시 설정을 유지합니다. 포화온도만 바꾸면 이 확인을 다시 요구하지 않습니다.

자세한 설명은 ZIP의 **`docs/workflow.md`**, 초기 데이터 안내는 **`docs/initial_calibration.md`**, NI 설치는 **`docs/ni_calibration.md`**를 참고하세요.

## 검증 범위

자동 검사 **182개** 및 배포 ZIP 압축 해제 후 검사를 통과했습니다. Chromium에서 전기로 3분 수집→초기 교정→별도 실험 오프셋→최종 TC/벌크→단계별 자동 커브, 중간 상수 저장·적용 시점, 최신 상수 재계산, 수동 데이터 보존, 새 실험 초기화, JSON/ZIP과 보정 이력, 새로고침·재실행·모바일을 확인했습니다. 실제 오디오 신호로 비프음·음소거·반복·임계온도 변경과 긴급중단도 확인했습니다.

**실제 NI는 3·4번 보정용 온도 읽기 전용이며, 1번 실험은 가상/CSV 입력입니다. 실제 레이저·셔터 출력 제어는 아직 미연결입니다.** 실제 NI 정확도와 Windows PC 실행은 이 클라우드에서 검증하지 않았습니다.
